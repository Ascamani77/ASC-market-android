cTrader Pepperstone Setup Checklist
====================================

✅ Step 1: Install service_identity module
   Command: pip install service_identity
   Status: DONE

⬜ Step 2: Get cTrader Open API Credentials
   1. Go to: https://openapi.ctrader.com/
   2. Sign in with Pepperstone account
   3. Create new application
   4. Set Redirect URI: http://localhost:8088/callback
   5. Copy Client ID and Client Secret

⬜ Step 3: Set PowerShell Environment Variables
   Run in PowerShell:
   $env:CTRADER_CLIENT_ID="your_actual_client_id"
   $env:CTRADER_CLIENT_SECRET="your_actual_client_secret"

⬜ Step 4: Run OAuth Setup Script
   Command: python .\ctrader_oauth_setup.py
   - Browser will open for authorization
   - Select your Pepperstone DEMO account
   - Copy the Access Token and Account ID from output

⬜ Step 5: Update local.properties
   Replace these values with real ones:
   - CTRADER_CLIENT_ID
   - CTRADER_CLIENT_SECRET
   - CTRADER_ACCESS_TOKEN
   - CTRADER_ACCOUNT_ID

⬜ Step 6: Rebuild Android App
   In Android Studio: Build → Rebuild Project

⬜ Step 7: Test Configuration
   Access in Kotlin code:
   BuildConfig.CTRADER_CLIENT_ID
   BuildConfig.CTRADER_ACCESS_TOKEN
   etc.
