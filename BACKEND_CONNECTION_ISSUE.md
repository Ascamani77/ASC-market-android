# Backend Connection Issue - Diagnosis

## Problem
The Android app is showing technical fallback scores (65%, 23.6%, etc.) instead of real AI scores from the backend.

## Root Cause
The backend AI server is **NOT accessible** even though processes are running:
- ✅ uvicorn process exists (PID 17948)
- ❌ Port 8000 is NOT listening
- ❌ Backend NOT accessible on localhost:8000
- ❌ Backend NOT accessible on 10.164.138.133:8000

## What's Happening
1. App tries to connect to `http://10.164.138.133:8000/latest-ai`
2. Connection fails (timeout)
3. App falls back to technical score calculation:
   - Compression (30%) + Ignition (25%) + Liquidity (25%) + Pressure (20%)
4. Result: You see scores like 65%, 23.6% (technical, not AI)

## Solution

### Step 1: Stop Any Existing Backend Processes
```powershell
# Kill all Python/uvicorn processes
Get-Process | Where-Object {$_.ProcessName -like "*python*" -or $_.ProcessName -like "*uvicorn*"} | Stop-Process -Force

# Verify they're stopped
Get-Process | Where-Object {$_.ProcessName -like "*python*" -or $_.ProcessName -like "*uvicorn*"}
```

### Step 2: Restart the Backend Properly
```powershell
cd c:\Users\HP\Documents\NEW_ASC
.\start_production_live.ps1
```

### Step 3: Verify Backend is Running
```powershell
# Wait 10 seconds for startup
Start-Sleep -Seconds 10

# Test localhost
Invoke-RestMethod -Uri "http://localhost:8000/latest-ai" -Method Get | Select-Object -First 1 -ExpandProperty final_decision | Select-Object -First 3 asset_1, pre_move_ai_score

# Test network IP
Invoke-RestMethod -Uri "http://10.164.138.133:8000/latest-ai" -Method Get | Select-Object -First 1 -ExpandProperty final_decision | Select-Object -First 3 asset_1, pre_move_ai_score
```

### Step 4: Check Port is Listening
```powershell
netstat -ano | findstr ":8000"
```

You should see something like:
```
TCP    0.0.0.0:8000           0.0.0.0:0              LISTENING       12345
TCP    [::]:8000              [::]:0                 LISTENING       12345
```

   ```powershell

   python --version
   ```

2. **Check Dependencies**:
   ```powershell
   pip list | findstr "fastapi uvicorn redis"
   ```

3. **Start Manually for Debugging**:
   ```powershell
   cd c:\Users\HP\Documents\NEW_ASC
   .\.venv\Scripts\Activate.ps1
   uvicorn ai_api:app --host 0.0.0.0 --port 8000 --reload
   ```

4. **Check for Port Conflicts**:
   ```powershell
   netstat -ano | findstr ":8000"
   ```
   If port 8000 is already in use, kill that process first.

### If Firewall is Blocking:

```powershell
# Allow Python through Windows Firewall
New-NetFirewallRule -DisplayName "Python AI Backend" -Direction Inbound -Program "C:\Users\HP\Documents\NEW_ASC\.venv\Scripts\python.exe" -Action Allow

# Or allow port 8000
New-NetFirewallRule -DisplayName "AI Backend Port 8000" -Direction Inbound -LocalPort 8000 -Protocol TCP -Action Allow
```
