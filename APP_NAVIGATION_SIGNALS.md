## 🎬 Step-by-Step Tutorial

### Tutorial 1: Finding Your First Signal

**Step 1:** Open the app
```
Tap app icon → App opens to Dashboard
```

**Step 2:** Go to Market Overview
```
You should already be on "Market Overview Tab"
(If not, tap the "Market Overview" tab at the top)
```

**Step 3:** Look at the top section
```
See "Overview — AI Decision Intelligence"
This is the Universal Overview Box
```

**Step 4:** Read the Bias
```
Look for "2. Dominant Bias Engine"
Read the "Bias" line:
- BULLISH = Buy signal
- BEARISH = Sell signal  
- NEUTRAL = No signal
```

**Step 5:** Check Confidence
```
Look at the "Confidence" percentage
- 70%+ = Strong signal ⭐
- 50-70% = Medium signal
- <50% = Weak signal
```

**Step 6:** Decide
```
If Bias is clear AND Confidence is high:
→ You have a signal!

If Bias is NEUTRAL OR Confidence is low:
→ No signal, wait
```

---

### Tutorial 2: Deep Dive Analysis

**Step 1:** Find an interesting asset
```
Scroll down to the asset list
Look for 🟢 Green or 🔵 Blue colors
```

**Step 2:** Click on the asset
```
Tap the asset row
The view will update to show that asset's details
```

**Step 3:** Check the Pre-Move Score
```
Look at the "AI PRE-MOVE SCORE" box
- 60-80% = PRE-MOVE (Ready) ⭐
- 80-100% = EXPANSION (Execute) ⭐
- <60% = Too early
```

**Step 4:** Scroll down to AI Progression
```
See where you are on the scale:
NOISE → STRUCTURE → COMPRESSION → PRE-MOVE → EXPANSION
```

**Step 5:** Check Entry Style
```
Scroll to "ENTRY STYLE" section
Look for "HIGH MATCH"
This tells you HOW to enter
```

**Step 6:** Combine all info
```
Bias + Confidence + Score + Phase + Entry Style
If all align → Strong signal!
```

---

### Tutorial 3: Quick Scanning

**Step 1:** Open Market Overview
```
Dashboard → Market Overview Tab
```

**Step 2:** Scroll through asset list
```
Don't read details yet
Just look at colors:
🔴 Red = Skip
🟠 Orange = Skip
🟡 Yellow = Maybe
🟢 Green = Interesting! ⭐
🔵 Blue = Very interesting! ⭐
```

**Step 3:** Click on green/blue assets
```
Tap each green or blue asset
Check the Bias and Confidence
```

**Step 4:** Make a shortlist
```
Note which assets have:
- Clear bias (BULLISH/BEARISH)
- High confidence (70%+)
- Active phase (PRE-MOVE/EXPANSION)
```

**Step 5:** Deep dive on shortlist
```
For each shortlisted asset:
- Check Pre-Move AI section
- Read Entry Style
- Note Key Levels
- Decide if you want to trade
```

## 🔍 Visual Indicators Cheat Sheet

### Colors
- 🔴 **Red** = NOISE (0-30%) → ❌ No Trade
- 🟠 **Orange** = STRUCTURE (30-45%) → ⏳ Wait
- 🟡 **Yellow** = COMPRESSION (45-60%) → 👀 Watch
- 🟢 **Green** = PRE-MOVE (60-80%) → ✅ Ready
- 🔵 **Blue** = EXPANSION (80-100%) → 🚀 Execute

### Text Labels
- **NOISE** = Market is random, no clear direction
- **STRUCTURE** = Pattern forming, too early
- **COMPRESSION** = Building pressure, getting ready
- **PRE-MOVE** = Signal forming, prepare to trade
- **EXPANSION** = Signal active, execute now!

### Bias Labels
- **BULLISH** = Buy signal (price expected to go up)
- **BEARISH** = Sell signal (price expected to go down)
- **NEUTRAL** = No clear direction, don't trade

### Confidence Levels
- **0-50%** = Low confidence, don't trade
- **50-70%** = Medium confidence, be cautious
- **70-85%** = High confidence, good signal ⭐
- **85-100%** = Very high confidence, strong signal ⭐

## 💡 Pro Tips for Finding Signals

### Tip 1: Start with the Overview Box
Always check the Universal Overview Box first. It's the AI's main decision.

### Tip 2: Use Colors for Quick Scanning
Don't read everything. Just scan colors. Green and Blue = worth investigating.

### Tip 3: Combine Multiple Indicators
Don't rely on just one thing. Check Bias + Confidence + Phase + Entry Style.

### Tip 4: Watch the Event Stream
Keep Event Stream open in background. It shows real-time changes.

### Tip 5: Don't Chase
If score is already 95%+, you might be late. Best entries are 65-85%.

### Tip 6: Respect the Phase
- NOISE/STRUCTURE = Too early, don't trade
- COMPRESSION = Getting ready, prepare
- PRE-MOVE = Signal forming, look for entry
- EXPANSION = Signal active, execute

### Tip 7: Check Entry Style
The AI tells you HOW to enter. Follow its recommendation.

### Tip 8: Use Invalidation Levels
Every signal has a "wrong" level. If price hits it, exit immediately.

## ❓ FAQ

**Q: I don't see "BULLISH" or "BEARISH" anywhere!**
A: Look in the Universal Overview Box → Section 2 "Dominant Bias Engine" → "Bias" line

**Q: Where is the Universal Overview Box?**
A: Dashboard → Market Overview Tab → Top section (scroll up if needed)

**Q: What if everything says "NEUTRAL"?**
A: No signals right now. Wait. Check back later or try different assets.

**Q: Can I get alerts when signals appear?**
A: Not yet (feature request). For now, check the Event Stream regularly.

**Q: How often should I check?**
A: Depends on your trading style:
- Day trader: Every 15-30 minutes
- Swing trader: Every 2-4 hours
- Position trader: Once or twice a day

**Q: What if signals conflict?**
A: Don't trade. Conflicting signals = uncertainty. Wait for clarity.

**Q: Is the AI always right?**
A: No. No system is 100% accurate. Always use stop losses and risk management.
